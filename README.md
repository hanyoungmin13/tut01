# 팀원 도감

포켓몬 도감 콘셉트로 제작한 팀 소개 웹페이지입니다.

## 주요 기능

- 메인 화면에서 팀원 선택
- 팀원별 상세 정보 확인
- 이전 팀원과 다음 팀원으로 이동
- 타입, 키, 분류, 성별, 몸무게, 특성 표시

## 팀원 소개

### 고범규

- 도감 번호: `No. 0001`
- 타입: 풀, 독
- 키: `0.7m`
- 분류: 씨앗포켓몬
- 성별: 남성
- 몸무게: `6.9kg`
- 특성: 심록

> 태어났을 때부터 등에 이상한 씨앗이 심어져 있으며 몸과 함께 자란다고 한다.

### 한영민

- 도감 번호: `No. 0002`
- 타입: 불꽃
- 키: `0.6m`
- 분류: 도롱뇽포켓몬
- 성별: 남성
- 몸무게: `8.5kg`
- 특성: 맹화

> 꼬리의 불꽃은 기분을 나타낸다. 즐거우면 흔들리고 화가 나면 맹렬히 불타오른다.
